修正点 1 · 机台质感：不再是灰线框。外框为金属机柜＋顶部霓虹跑马灯招牌，板面有纵深光影、金色立体钉阵、发光奖槽（亮灯出口）与沉没暗口、右侧弹簧发射杆、底部出珠托盘——老虎机/柏青哥机台观感。
修正点 2 · 30° 倾斜：默认是机台向后仰 30° 的真实透视倾斜（CSS perspective + rotateX(30deg)），板面有纵深、球沿后仰面板"下坡"滚动，符合真实机台。点上方按钮可切回旧方案（平面 2D 旋转成平行四边形）对比——那就是之前"丑且不对"的样子。
HUD（余额/倍数/剩余）始终为屏幕正向独立图层，不随板倾斜，保证文字可读。
修正点 3 · 弹射轨道：右侧新增竖向发射道（顶部亮灯入口连到钉板右上），弹珠自底部弹起、沿道升至顶端、转入钉板后穿钉下落——对应真实柏青哥"先上膛再落入钉阵"的轨道。钉板整体已上移，下方留白给发射道与出口。
修正点 4 · 控制区移出画面：「加注 / 拉杆发射」不再浮在游戏画面上方遮挡出口与出珠盒子，改放到机柜下方的专用控制条；发射道底部保留发射旋钮（画面内的发射器本体），与下方拉杆发射按钮呼应。
修正点 5 · 出珠口贴近钉板 + board 上移：出珠口/亮灯出口上移，与钉板间距由 ~68px 收到 ~50px；整块板面上移（top:34→12）更贴近顶部。

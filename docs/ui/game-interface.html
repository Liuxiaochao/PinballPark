3. 界面信息架构与状态机

3.1 信息架构

  • 顶部招牌：品牌 LED 跑马灯。
  • 招牌下状态行：弹珠余额、领珠 +88、积分卡。
  • 中部弹珠板：钉阵、发射通道、倍数/亮灯出口、出珠盒、沉没区。
  • 左边缘：抽屉触发边。
  • 底部控制台：投入 5 + 加珠 +1 + 按住拉杆。
  • 结果态：吐票结算带从机台下部滑出。
透视分组：倾斜组 = 钉板、发射通道、倍率显示。屏幕正向组 = 顶部招牌、状态行/领珠、亮灯出口、左抽屉、出珠盒/沉没区、底部控制台、吐票结算带。

3.2 状态机

IDLE_START → STARTING → BET_READY → CHARGING → SIMULATING → RESULT_TRAY

状态主行为可用入口禁用内容
IDLE_START开始游戏抽屉、领珠发射、加珠
STARTING等待开局无所有操作
BET_READY加珠、发射抽屉、领珠无
CHARGING蓄力/取消/发射无抽屉、领珠、加珠、投入
SIMULATING球飞行无所有操作
RESULT_TRAY命中：再来 / ×2 / 商城；沉没：再来 / 商城抽屉、领珠主屏控制台
  • 取消：CHARGING → BET_READY，不扣珠、不请求服务端。
  • 结算：RESULT_TRAY 内“再来”直接再扣 5 颗进 STARTING；“看视频 ×2”只翻弹珠奖励，积分卡不重复发。

4. 主屏分区与节点规范

设计分辨率：720×1280，竖屏。

分区用途屏幕关系
1. 顶部招牌区品牌 LED 跑马灯屏幕正向
2. 状态行/领珠区弹珠、领珠 +88、积分卡屏幕正向
3. 弹珠板/物理演出区钉阵与物理演出主体60° 倾斜组
4. 发射通道发射杆、蓄力与取消反馈60° 倾斜组
5. 倍数/亮灯出口区本局倍数与亮灯出口倍率显示：60° 倾斜组；亮灯出口：屏幕正向
6. 出珠盒/沉没区奖励珠与沉没视觉落点屏幕正向
7. 左抽屉触发边任务/商城/概率/设置入口屏幕正向
8. 底部控制台投入、加珠、发射屏幕正向
9. 吐票结算带命中/沉没结果与动作屏幕正向
透视规则：钉板、发射通道、倍率显示组成倾斜组，暂按 60° 后仰透视渲染；其余界面元素不随倾斜组旋转。倾斜角度作为可配置参数，后续由人工统一 PRD/架构/代码。

5. 页面/状态细则

5.1 IDLE_START

  • 底部控制台显示：投入 5（只读）、开始（主按钮）。
  • 顶部领珠、左抽屉可用。
  • 弹珠板播放待机演示，不显示本局倍数，不扣珠。

5.2 STARTING

  • 点“开始”后按钮变“开局中”，自动扣 5 颗。
  • 服务端返回倍数和亮灯出口后才进入 BET_READY。
  • 失败时 Toast 并回到 IDLE_START。

5.3 BET_READY

  • 底部控制台显示：投入 5、加珠 +1、按住拉杆。
  • 加珠 +1 每点一次加 1 颗，支持快速连点；按住连续加。
  • 总投入上限 99，且不能超过弹珠余额。
  • 有效投入和“预计得珠 = 投入 × 当前倍数”实时刷新。
  • 抽屉和领珠可用。

5.4 CHARGING

  • 按住蓄力，弹珠板/发射杆同步反馈。
  • 松手发射。
  • 移出发射热区或拖入取消区松手为取消，不扣珠、不请求服务端，回 BET_READY。
  • 蓄力期间抽屉、领珠、投入、加珠全部禁用。

5.5 SIMULATING

  • 球飞行期间所有游戏控件禁用，不弹窗。

5.6 RESULT_TRAY

  • 吐票结算带滑出。
  • 命中显示奖励和积分卡；沉没显示明确沉没文案。
  • 命中按钮：看视频 ×2、再来、去商城。
  • 沉没按钮：再来、去商城。
  • “再来”直接再扣 5 颗进 STARTING。
  • “看视频 ×2”只翻弹珠奖励，积分卡不重复发；成功后按钮禁用。
  • “看视频 ×2”失败：奖励回退到原值、按钮恢复可用、Toast 提示“未获得翻倍”。
  • 抽屉和领珠可用。

6. 交互与动效规格

交互规格
蓄力发射按住填充 1.4s ± 0.1s 满；松手时蓄力 ≥4% 才发射
取消松手点距发射键中心超过 120px，或拖入独立取消区（96×96），即取消
加珠单击 +1；长按首个重复延迟 300ms，之后每 100ms +1
吐票结算带260ms ± 20ms 从机台下部滑出，不弹窗
左抽屉200ms ± 20ms 从左侧滑出，机台压暗
顶部领珠显示“今日剩 N/6”；验真后 +88 数字滚动 220ms
亮灯出口服务端返回后 200ms ± 20ms glow 点亮
看视频 ×2成功：N→2N，按钮禁用；失败：回退原值、恢复按钮、Toast
按钮按压按下 scale 0.96 + 亮度变化，回弹 80ms ± 20ms

7. 音效与触觉反馈

7.1 音效

事件触发状态实现约束
按钮/开始/加珠对应控件按下Web Audio 合成默认，音量 0.5
蓄力/松手发射CHARGING 起止蓄力短滑音，发射单次播放
球碰钉SIMULATING 碰撞最小触发间隔 80ms，音量 0.35
落出口/吐票SIMULATING 落定 / RESULT_TRAY 滑出单次播放，音量 0.5
积分卡/命中/沉没RESULT_TRAY 展示单次播放，命中音量 0.6，沉没音量 0.4
抽屉开合/领珠到账抽屉滑入滑出 / 领珠验真成功单次播放，音量 0.4

7.2 触觉

  • 发射、命中：wx.vibrateShort({ type: 'medium' })。
  • 落口、沉没：wx.vibrateShort({ type: 'light' })。
  • 连续震动最短间隔 300ms；连点加珠不逐次震动。
  • API 不可用或系统关闭触觉时静默跳过，不阻塞流程。
  • 系统“减少动态效果”开启时不触发触觉。

8. 微信适配、安全区、触控热区

  • 项目配置锁定竖屏；横屏设备不旋转画布，按等比缩放居中。
  • 安全区来源：wx.getWindowInfo().safeArea，兼容旧接口 wx.getSystemInfoSync()。
  • 顶部避让：安全区顶部 + 16 设计像素；底部避让：窗口底部到安全区底 + 16 设计像素。
  • 缩放：设计稿 720×1280，scale = min(screenW/720, screenH/1280)，等比缩放并居中，禁止拉伸文字。
  • 机台外框四边内边距 ≥16 设计像素。
  • 开始、加珠 +1、按住拉杆、领珠、抽屉触发边至少 88×88 设计像素。
  • 取消区为独立 96×96 设计像素热区，放在发射键附近；松手点距发射键中心超过 120px 也视为取消。
